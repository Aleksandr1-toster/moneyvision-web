# MoneyVision — сайт для Vercel

## Публикация на Vercel через GitHub
1. Распакуйте архив.
2. Создайте новый публичный или приватный репозиторий GitHub и загрузите в корень `index.html` и `README.md`.
3. Откройте https://vercel.com/new и войдите через GitHub.
4. Выберите репозиторий MoneyVision и нажмите Deploy. Настройки сборки оставьте по умолчанию: это статический сайт, команда сборки не нужна.
5. После публикации Vercel выдаст адрес вида `имя-проекта.vercel.app`.

Можно также импортировать репозиторий в Vercel через Dashboard → Add New → Project.

## Что внутри
`index.html` — весь сайт (HTML, CSS и JavaScript). Внешние библиотеки и сервер не нужны.

## Математические допущения
Годовая эффективная ставка R переводится в месячную: i=(1+R)^(1/12)-1. В конце каждого месяца сначала начисляется доходность, затем добавляется взнос. Реальная стоимость = номинальный капитал/(1+инфляция)^лет. Это учебная модель, а не финансовый совет: доходность не гарантируется, налоги, комиссии и рыночные колебания не учитываются.
